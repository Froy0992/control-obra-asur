# Control de Obras

App para seguimiento y control de contratos de obra de infraestructura aeroportuaria: avance físico vs. programado, estimaciones y su resumen (anticipo, amortización, IVA, saldo por estimar), convenios modificatorios, pendientes y acuerdos de minuta, bitácora con folio, evidencias con foto y GPS, y documentos (contratos, convenios, fianzas, planos).

- Funciona en computadora y celular, y sin señal. Para instalarla: Android (Chrome) menú ⋮ → "Instalar app"; iPhone (Safari) Compartir → "Agregar a inicio".
- Tiempo real: en **Ajustes → Sincronización** se conecta a un proyecto gratuito de Supabase. El código SQL para prepararlo viene en esa pantalla.
- Enlace (con GitHub Pages activo desde la rama main): https://froy0992.github.io/control-obra-asur/
